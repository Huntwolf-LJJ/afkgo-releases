# AFKGo 官方下载

本仓库仅分发 AFKGo Windows x64 安装包、校验文件和用户更新说明，不包含客户端或服务端源码。

[下载最新稳定版](https://github.com/Huntwolf-LJJ/afkgo-releases/releases/latest)

## 安装与更新

- 支持 Windows 10 / 11 64 位。安装前请停止任务、断开串流，并关闭所有 AFKGo 窗口。
- 安装升级保留本机身份、主机配对、配置与比赛历史。
- 0.4.0 用户需手动安装更新版一次；带更新中心的版本支持手动检查、下载与确认安装。
- 客户端使用独立 Ed25519 公钥验证更新清单，并校验安装包大小和 SHA-256。
- 下载失败时可以稍后重试，或从对应 Release 手动下载安装包。本期没有强制更新或无人值守安装。

请以完整发布的稳定版为准；不要从其他来源运行不明安装文件。
